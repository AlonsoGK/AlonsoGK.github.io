Here is a basic tutorial for VIM:

First off, Vim is a basic text editor that is very old ans is based around being able to use the keyboard for everything, because this thing was gere before the mouse was invented!
To get start ed with Vim, open the terminal on your device and create a file sim ply by typing:vim (file name) and clicking enter.
Then when you are in Vim you will see a blank black screen with come numbers on t he side, from here you need to know basic commands to do anything

  1. Use either arrow keys or HJKL to move around o n the screen.
  2. Click I to enter insert mode, this is how you can write or change things
  3. While in insert mode you have to use arrow keys to move ar ound and you use your basic commands when typing like enter to make a new line and also another tip is if your trying to move around fast hold shift while u sing arrow keys and you skip around lines super quick.
  4. Now when you want to get out of INSERT mode, click escape and click (at the same time) shift + ;
  5. This will pop up 2 dots at the bottom where you can type W or Write to save everything you wrote on to the file then click enter and do the same thing but this time put q to exit out if Vim
  6. If you want to exit without saving do the same thing but type q! which will force quit.
